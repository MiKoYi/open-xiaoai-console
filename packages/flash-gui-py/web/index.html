刷机

给音箱刷入补丁固件，开启 SSH。支持 LX06 和 OH2P。

刷机有风险，变砖自负。 仅支持 LX06 / OH2P，小白不建议尝试，请先阅读免责声明。

部署

部署 Home Mate（小瑞）核心，或给音箱安装 XiaoAI-Plus（豆包实时语音）。

Home Mate 支持：小爱音箱 Pro（LX06）、Echo Dot 2、Android 网关；不支持 OH2P（OH2P 请用 XiaoAI-Plus）。
管理界面
管理界面地址在「配置 → Home Mate」填写；连接后会把 Home Mate 自带的 Vue 3 控制台嵌到下方。
部署 / 更新核心（Docker over SSH）
SSH 参数在「配置 → Home Mate」里设置；镜像：ghcr.io/yes999zc/home-mate:latest（主机需要能访问 ghcr.io）。
XiaoAI-Plus 仅支持 Xiaomi 智能音箱 Pro（OH2P）；LX06、Echo Dot 等其它机型请用 Home Mate。
安装 / 更新（连接参数在「配置 → XiaoAI-Plus」）
离线包用 xiaoai-doubao-oh2p-v0.1.0.tar.gz； 控制台会自动补齐 KWS 模型、词表和 CA，再经 SSH 上传安装，音箱不需要外网。
「安装 / 更新」由控制台下载 xiaoai-doubao v0.1.0 并补齐模型后上传；装完到「配置 → XiaoAI-Plus」填 API Key 和唤醒词。

配置

分别配置 Home Mate 与 XiaoAI-Plus 的连接和运行参数；部署页只负责安装 / 更新。

SSH 部署参数
「部署 → Home Mate」的部署 / 连接 / 状态按钮都使用这里的参数。 Home Mate 的 LLM / ASR / TTS 都走 API Key，填在它自带控制台的「服务」页。
连接音箱
需要音箱已刷补丁固件并开启 SSH（root）。连接信息会记住（含密码，保存在本机 state.json）。
豆包实时语音配置
API Key 从火山引擎「豆包语音」控制台获取；保存后写入 /data/xiaoai-plus/config.ini（0600）， 唤醒词会编码成 keywords 并上传，重启后生效。
音色用豆包 App 同款 Vivi 2.0：zh_female_vv_uranus_bigtts； 也可以填小何 2.0（zh_female_xiaohe_uranus_bigtts）等 S2S 音色。
模型版本（model）是豆包端到端实时语音的版本号，默认 1.2.6.1； 不确定就保持默认，服务端不支持时启动会失败并写进日志。
